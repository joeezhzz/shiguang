# 「拾光」项目规划定稿（v1.1）

> 创建：2026-08-24 · 状态：技术验证周 · 截止：2026-10-15（物光创新实验室招新提交）

## 一句话定位

一个 PC 端信息收纳工具——微信/网页/截图里的重要信息，复制或拖拽 3 秒收进「拾光」，
AI 自动分类，看板+日历双视图查阅，到期自动提醒。

## 核心使用流程

| 场景 | 操作 | 耗时 |
|---|---|---|
| 文本（聊天记录、通知） | 复制 → `Ctrl+Shift+V` → 确认 AI 标签 → 回车 | 3秒 |
| 图片（截图、报名表） | 微信右键复制图片 / 截图工具 → 快捷键 → 自动保存+OCR | 3秒 |
| 文件（PDF、表格） | 直接拖进浮窗 → 回车 | 3秒 |
| 查阅 | 托盘图标 → 软件内弹出看板窗口（状态列/主题列切换 + 日历 + 全文搜索） | — |

## 作品形态

**Windows 桌面软件（PySide6）**，包含：
- 托盘常驻（可选开机自启），平时完全隐形、不监听剪贴板
- 悬浮窗：全局快捷键唤出（默认 `Ctrl+Shift+V`），读取剪贴板一步录入
- 内嵌看板窗口（QtWebEngine 渲染 HTML/CSS/JS，浏览器全程不出现）
- 设置窗口

## 功能清单（本期范围）

**P0 核心**
- 悬浮窗：快捷键唤出 + 托盘常驻
- 录入：文本粘贴 / 图片 / 文件拖拽，一步到位，零手动保存
- AI 分类建议 + 确认弹窗（DeepSeek API；断网自动降级为规则分类）
- SQLite 本地存储 + 文件库，数据全在本地
- 看板双模式（状态列 / 主题列）+ 日历视图 + 全文搜索

**P1 亮点**
- 图片离线 OCR（RapidOCR，图片里的字可搜索）
- 到期提醒：全局开关 + 提前天数自定义 + 每条卡片单独设置
- 卡片编辑 / 删除 / 归档
- 数据导出备份（JSON）

## Roadmap（二期，仅蓝图，本期不实现）

- AI 周报：每周自动回顾收纳内容
- 手机端入口：官方 iLink Bot 通道（无封号风险，手机转发即归档）
- （可议）数据云同步

## 数据模型（一张卡片）

```
内容（文本/图片/文件路径）
来源（微信复制 / 截图 / 网页 / 手动）
主题标签（内置：学习方法/考研保研/竞赛/生活小妙招/就业赚钱，可增删）
重要程度：高 / 中 / 低（色条区分）
效用期：短期任务 / 长期计划 / 永久参考
时间：开始/截止时间（可选，自行设定，显示在日历上）
状态：待处理 / 进行中 / 已完成 / 已归档
OCR文本 · 备注 · 创建时间
```

## 界面设计

- **悬浮窗**：约 400×300、圆角置顶可拖拽；输入区 + AI 建议标签区 + 快捷按钮
  （重要度 / 效用期 / 截止：3天·1周·1月·自定义）
- **看板页**：顶部搜索 + 过滤器（主题/重要度/状态/效用期）+ 双模式切换 + 日历按钮；
  卡片 = 内容摘要 + 标签 + 重要度色条 + 截止倒计时
- **风格**：浅色简洁打底，具体视觉待内容细节确定后调用 UI 设计 skill 细化

## 技术栈

| 部分 | 选型 | 说明 |
|---|---|---|
| 悬浮窗/托盘/看板壳 | PySide6 + QtWebEngine | 内嵌看板窗口 |
| 看板渲染 | Flask 本地服务 + HTML/CSS/JS | 浏览器不可见，QtWebEngine 内嵌 |
| 自动分类 | DeepSeek API | 断网降级规则分类 |
| OCR | RapidOCR（已装） | 离线免费，图片文字进搜索索引 |
| 存储 | SQLite + 本地文件库 | 零配置，隐私安全 |

## 难点与对策（作品「问题分析」素材）

| 难点 | 对策 |
|---|---|
| 微信数据库加密、导出工具繁琐 | 不碰数据库：日常复制/拖拽一步到位 |
| 微信自动化封号风险 | 已排除；官方 iLink Bot 仅作二期蓝图 |
| API 断网/不稳定 | 规则分类降级，功能不瘫 |
| 图片内容搜不到 | RapidOCR 离线识别进索引 |
| 大图 OCR 慢 | 压缩后再识别 |
