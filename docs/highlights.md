## 一、项目一句话

**拾光** —— 一款 Windows 桌面信息收纳软件：把你在微信、网页、截图里看到的重要信息，复制或拖拽一下，3 秒收进「拾光」，AI 自动分类整理，看板 + 日历双视图查阅，到期自动提醒。白天拾落花，夜里拾流星。

## 二、解决的痛点

日常会把重要的东西（图片、聊天记录、公众号文章、文件）随手存进微信，久而久之：主题混杂（学习方法 / 考研保研 / 竞赛 / 生活妙招 / 就业赚钱…）、时效不一（短期任务 / 长期计划 / 永久参考）、找不到、懒得整理。拾光把这些「信息碎片」一键收进来，自动归类、可视化、可检索、到期提醒。

## 三、技术栈

| 层 | 技术 |
|---|---|
| 语言 | Python 3.13 |
| 桌面 GUI | PySide6 6.11（系统托盘 + 悬浮窗 + QtWebEngine 内嵌看板窗口） |
| 本地服务 | Flask 3.1（仅本机 127.0.0.1:8765） |
| 看板前端 | 原生 HTML / CSS / JS（零框架）+ Canvas 背景动画 |
| 数据存储 | SQLite（本地）+ 文件库（原始文件归档） |
| AI 分类 | DeepSeek API（结构化分类 + 聊天记录整理），断网自动降级为规则分类 |
| OCR | RapidOCR（离线，备用） |
| 其他 | pyperclip（剪贴板）、Pillow（图片处理）、Windows 原生通知 |

**设计原则**：数据 100% 本地存储（隐私安全）；AI 优先 + 规则降级（断网也能用）；零第三方运行时依赖。

## 四、核心功能

1. **一步到位收纳**：全局热键 `Ctrl+Shift+V` 唤出悬浮窗，自动读取剪贴板（文本 / 图片 / 文件），文件也可直接拖入——不需要手动保存文件、不需要浏览文件夹。
2. **AI 自动分类**：主题（内置 6 类 + 自动收集自定义）、重要度（高/中/低）、效用期（短期/长期/永久）、截止日期自动识别。
3. **聊天记录结构化整理**：识别多轮对话 → 提炼「主观点」+「分支」（问答 / 补充），原文完整保留。
4. **图片 / 文件收纳**：图片存原始分辨率（放大清晰）；文件一键用系统程序打开；公众号链接可直接点开。
5. **看板 + 日历双视图**：状态列 / 主题列切换；日历展示截止日期 + 手动「时间锚点」📌。
6. **到期提醒**：Windows 原生通知，全局默认 + 单卡设置，防重复提醒。
7. **全文搜索**：内容 / 标签 / 主观点 / 备注均可检索。
8. **双主题**：暖白晨光（浅色）+ 深夜拾光（深色），一键切换并记忆，配背景氛围动画（落花 / 流星 + 星空）。

## 五、产品亮点（为什么值得看）

- **「信息零丢失」底线**：AI 整理只是附加层，`content` 字段永远保存完整原文，任何整理结果都不丢原始信息。
- **三层 AI 信任保障**：① 保存前悬浮窗预览确认（可改主题/重要度/截止）→ ② 保存后详情页可编辑 → ③ 「仅存原文」兜底。
- **贴心的隐私设计**：程序平时完全隐形、不读剪贴板，只在按下快捷键唤出时读取；数据全部本地。
- **对中文聊天记录的真实适配**：微信复制消息**不带昵称**，专门做了纯消息流识别 + AI 语义判断问答，这是普通收藏夹做不到的。

## 六、技术难点与解决（评审重点）

开发过程中遇到并解决的真实问题：

| 问题 | 解决 |
|---|---|
| 全局热键 `RegisterHotKey` 注册成功但 Qt 不派发 `WM_HOTKEY`（9 轮诊断定位） | 改用 `GetAsyncKeyState` 轮询 + 保存对象引用防 GC |
| 微信复制聊天记录不带昵称，无法按「人名: 内容」解析 | 纯消息流特征识别（多行短句 + 含问句）+ AI prompt 按语义判断谁问谁答 |
| 真实库 `ALTER TABLE` 加的列是 TEXT 类型，读出来是字符串，与整数比较直接崩溃（提醒功能从未工作） | 字段读取一律 `int()` 强转；补字符串兼容测试 |
| 测试污染了真实用户数据（settings 被写成关闭提醒） | 测试全部隔离到临时库（DB / media / settings 三件套重定向） |
| 微信复制图片/文件时剪贴板文本是 `file:///` 本地路径，污染内容字段 | 有媒体时忽略剪贴板文本；文件用文件名代替 |
| 图片放大模糊 | 磁盘保存原始分辨率原图，缩放只用于预览显示 |
| QtWebEngine 内嵌窗口缓存静态文件，UI 改动不生效 | 禁用静态文件缓存（no-cache） |
| 无 GUI 测试环境（offscreen）差异：Qt 画不出文字、剪贴板不通 | 测试改用 PIL 生成验证图、Qt 剪贴板写入 |
