拾光 · UI 设计方案

用你的真实卡片数据渲染的三个视觉方向。每个方向都遵循「简洁 + 克制 + 高级」的原则， 区别在于色温、情绪和「一个记忆点」。看实际观感后告诉我选哪个（或想怎么混合）。

方向 A · 温暖

暖白晨光

暖米白纸张底色 + 温润墨色文字 + 琥珀金点缀。像清晨摊开一本笔记，安静、有书卷气。呼应「拾光」= 拾取时光碎片的温暖感。
记忆点：卡片左缘一条琥珀金「书签线」，hover 时柔和上浮。
