# 2026-08-27 开机自启 + 托盘图标排查

## 背景
- 重启电脑后拾光不自动运行（当时还没设置自启）；D 盘同时有 `启动拾光.vbs` 和 `启动拾光.bat`，用户不知道点哪个
- 将 bat 改名为「调试启动拾光.bat」（调试专用，会弹控制台），日常统一用 vbs

## 处理
1. **开机自启**：启动文件夹（`shell:startup`）创建指向 `启动拾光.vbs` 的快捷方式 `拾光.lnk`，目标为 pythonw.exe + `src/main.py`，工作目录 `D:\hermes\shiguang`。用户可随时自删快捷方式，比注册表/计划任务透明
2. **托盘图标"不出现"排查**：
   - `netstat` 无 8765 监听 + `data/run.log` 无今日记录 → 判断拾光其实没在运行（之前终端里启动 pythonw 的命令超时被杀）
   - UIAutomation 枚举 `Shell_TrayWnd` 后代找不到拾光按钮 → 一度怀疑图标未创建；但代码审查确认 `tray.show()` + 动态画图标（深蓝 `#2b2d42` + 白「拾」）逻辑正常
   - 用 `cscript //nologo 启动拾光.vbs` 干净启动 → 端口监听、日志正常、页面加载 → **用户确认托盘图标出现、看板可打开** ✅

## 教训
1. **git-bash 里直接运行 pythonw.exe 会阻塞**（bash 捕获其输出管道，GUI 进程不退 → 命令超时 exit 124，进程可能被连带杀掉）。启动 GUI 程序必须用 `cmd //c start` 或 `cscript //nologo xxx.vbs`（WScript.Shell.Run 异步，立即返回）
2. **UIAutomation 枚举 Shell_TrayWnd 不一定能看到通知区域图标**（可能收在溢出区/未展开），托盘图标是否显示以用户实际看到为准，别拿枚举结果当"没显示"的证据
3. 排查"托盘图标没出现"的正确顺序：**进程 → 端口 → 日志 → 代码逻辑**，最后才是系统托盘状态；先确认程序到底跑没跑
