# 拾光 · Shiguang

> 将微信里觉得重要但又杂乱的信息，一键收集整合，AI 帮你整理好。

**拾光**是一款 Windows 桌面信息收纳工具：按下全局热键 `Ctrl+Shift+V`，把微信、网页、截图、文档里看到的重要信息（聊天记录、公众号文章、图片、文件）一键收进「拾光」；AI 自动分类整理成主题清晰的卡片；看板 + 日历双视图随时查阅；快到期的内容自动提醒。**不只微信——任何场景复制的内容都能收。** 白天拾落花，夜里拾流星。

## 为什么做这个项目

我习惯把觉得重要的东西（学习方法、考研保研、竞赛通知、生活小妙招…）随手发到微信里存着，时间一长就变得又杂又乱：主题混在一起、有的短期有效有的长期有用、想找的时候翻半天——**信息存了等于没存**。

拾光就是为这个真实痛点做的：让"收藏"变成"整理"，让重要信息**找得到、看得见、不遗忘**。

## ✨ 核心亮点

- **悬浮窗 + 全局热键**：`Ctrl+Shift+V` 随时唤出，不局限于微信——微信、网页、文档、截图，任何场景复制/拖拽的内容都能一键收纳
- **AI 整理 + 三层保障**：AI 自动分类、提炼观点，但**原文 100% 保留** + 保存前**预览确认** + 详情页**可编辑**，信息零丢失
- **看板 + 日历 + 到期提醒**：双视图随时查阅，到期自动弹 Windows 原生通知，重要信息不遗忘
- **全本地 + 可离线**：数据全部存在本机（SQLite + 文件库），不读剪贴板（仅按需读取）；断网时 AI 自动降级为规则分类，核心功能不受影响

## 功能特性

- **⚡ 一步到位收纳**：全局热键 `Ctrl+Shift+V` 唤出悬浮窗，自动读取剪贴板（文本 / 图片 / 文件），文件也能直接拖入——不需要手动保存、不需要浏览文件夹
- **🤖 AI 自动分类**：DeepSeek 自动识别主题（6 大类 + 自定义）、重要度（高/中/低）、效用期（短期/长期/永久）、截止日期
- **💬 聊天记录结构化整理**：识别多轮对话，提炼「主观点」+「分支」（问答 / 补充），原文 100% 保留
- **🔗 链接 / 文件直接打开**：公众号链接一键在浏览器打开，Word 等文件一键用系统程序打开
- **🖼 图片原始保存**：磁盘存原始分辨率，点击放大清晰
- **📊 看板 + 日历双视图**：状态列 / 主题列切换；日历展示截止日期 + 手动时间锚点 📌
- **⏰ 到期提醒**：Windows 原生通知，全局默认 + 单卡设置，防重复提醒
- **🔍 全文搜索**：内容 / 标签 / 主观点 / 备注均可检索
- **🌗 双主题 + 氛围动画**：暖白晨光 / 深夜拾光一键切换，背景有落花 / 流星 + 星空动画（呼应"拾光"）
- **🔒 独立运行**：托盘常驻 + 开机自启，双击启动后即可用，无需一直开着终端或 IDE

## 快速开始

### 当前形态

目前拾光以**源码 + 本机运行**的方式提供：需要 Windows + Python 3.10+ 环境，克隆后 `pip install -r requirements.txt` 即可运行。

> 正在打包为**免安装的 exe**（`PyInstaller`），打包完成后任何人双击即可使用、无需安装 Python——见 [路线图](#路线图)。

### 环境要求

- Windows 10 / 11
- Python 3.10+

### 安装

```bash
git clone https://github.com/joeezhzz/shiguang.git
cd shiguang
pip install -r requirements.txt
```

### 运行

```bash
python src/main.py
```

双击 `启动拾光.vbs` 也可（静默启动，无控制台窗口）。首次运行如需 AI 分类，请在设置中填入自己的 DeepSeek API Key；不填也能用（自动走规则分类）。

### 使用

1. 按 `Ctrl+Shift+V` 唤出悬浮窗（自动读取剪贴板内容）
2. `Enter` 让 AI 分析整理 → 预览确认 → `Enter` 保存
3. 单击托盘图标打开看板，查看 / 编辑 / 检索卡片
4. 给卡片设置截止时间，到期自动提醒

## 开发过程中遇到的问题与解决

- **全局热键失灵**：`RegisterHotKey` 注册成功但 Qt 不派发 `WM_HOTKEY`（9 轮诊断）→ 改用 `GetAsyncKeyState` 轮询
- **微信复制不带昵称**：聊天记录无法按「人名: 内容」解析 → 纯消息流特征识别 + AI 语义判断问答
- **提醒功能静默失效**：旧库 `ALTER TABLE` 加的列是 TEXT 类型，与整数比较崩溃 → 读取一律 `int()` 强转 + 补兼容测试
- **测试污染真实数据**：测试脚本把用户的提醒设置写成了关闭 → 测试全部隔离到临时库
- **独立运行的窗口被"吞"**：后台启动的进程弹窗被 Windows 前台锁定阻止 → 原生 API 强制置顶
- 完整排障过程记录在 `docs/devlog/`（评审材料）
